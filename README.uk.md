## Проблема

Платне паркування в містах є, а контролю оплати майже немає. За бенчмарком Києва, кожен третій водій не платить, бо ймовірність штрафу низька. Інспектори ходять «за звичкою», а не туди, де реально не платять. Міста оцифрували **оплату**, але **перевірку** не оцифрував ніхто.

VILNO не конкурує з Приват24 чи «Київ Цифровий». Він працює поверх них: перевіряє присутність і дає місту дані для контролю.

## Як це працює

Три сторони однієї системи, три екрани у браузері телефона.

| | Хто | Що робить |
|---|---|---|
| **`/driver`** | Водій | Бачить мапу майданчиків, фотографує авто на старті й фініші, платить за реальні хвилини, але не більше денного ліміту зони |
| **`/inspector`** | Інспектор | Наводить камеру на номер і за секунду бачить статус оплати. Штраф оформлює тільки людина |
| **`/city`** | Місто | Дашборд: де неоплата, де вигідно їхати, куди йти в маршруті |

### Статуси скану

| Статус | Значення |
|---|---|
| `active` | Сесія активна на цьому майданчику (або закрита ≤ 10 хв тому: водій від'їжджає) |
| `unpaid` | Оплати немає. Якщо оплачено на іншому майданчику, є окрема позначка |
| `closed_but_present` | Сесію закрито понад 10 хв тому, а авто досі тут: ловить «сфоткав фініш і лишився» |
| `unknown` | Модель не впевнена або майданчик поза робочими годинами: ручний ввід |

### Тарифікація: похвилинно з лімітом

Водій нічого не вибирає. Платить за хвилини, а система гарантує, що він не заплатить більше за «пакет», як fare capping у міському транспорті.

| Зона (припущення з ціни) | Тариф | Ліміт |
|---|---|---|
| `center` | 20 грн/год | без ліміту |
| `standard` | 10–15 грн/год | 3 × тариф на день |
| `market` | 3–5 грн/год | без ліміту |

Поза `openingHours` паркування безкоштовне. Приклад: 10 грн/год і 4 години стояння дають 30 грн, а не 40.

### Куди їхати інспектору

```
вигода = авто × частка_неоплати × (20 × тариф) × 0,63      →  їхати, якщо вигода > 200 грн
```

Штраф за неоплату: 20 × вартість години (ст. 152-1 КУпАП). 0,63 і 200 грн є припущеннями, і в інтерфейсі вони підписані як припущення.

## Принципи

- **Система рекомендує, рішення ухвалює людина.** В інтерфейсі немає кнопки «оформити штраф».
- **Хибний номер гірший за `unknown`.** Якщо модель не впевнена, вона мовчить, і номер вводять вручну.
- **Приватність.** CV повністю локальний, зовнішніх API немає. Фото обробляються в пам'яті й не зберігаються. Номери зберігаються лише як HMAC-SHA256.
- **Скарга «місць немає» не є інструментом перевірки чужих номерів.** Клієнт завжди отримує однакове `{"ok": true}`.
- **Чесне демо.** Лоти, адреси, координати й тарифи беруться зі справжнього набору даних. Усе симульоване має бейдж «Симуляція».

## Дані

Основа: набір ЧМР на [data.gov.ua](https://data.gov.ua) «Реєстр майданчиків для паркування Чернівецької МТГ» (станом на 27.03.2025).

- **55 платних рядків → 39 майданчиків**, 848 місць, плюс безкоштовні майданчики (на мапі сірі).
- 26 майданчиків МіськШЕП і 7 приватних операторів.
- Оригінал лежить у `data/raw/`, а перелік дефектів набору й правок — у [`DATA.md`](DATA.md).

OpenStreetMap contributors і data.gov.ua зазначено на мапі в додатку.

## Запуск

Потрібні Python 3.11+ і Node.js.

```bash
cp .env.example .env            # заповніть PLATE_HMAC_KEY і DEMO_TOKEN
```

**Бекенд**

```bash
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000   # порожню БД заповнить імпорт лотів із data/raw
pytest
```

**Фронт**

```bash
cd frontend
npm install
npm run dev -- --host                  # Vite проксує /api → :8000
npm run build
```

Далі відкрийте `/driver`, `/inspector` або `/city`. Ваги CV докачуються при першому запуску, після цього все працює офлайн.

**Демо-панель.** Ендпоінти `/demo/*` (перемотка серверного годинника, скидання) вимагають заголовок `X-Demo-Token` зі значенням `DEMO_TOKEN`. Серверний час — єдине джерело часу, клієнтський не приймається.

**Docker**

```bash
docker build -t vilno-api:latest .
cd deploy && docker compose up -d --build   # потрібен deploy/.env.prod
```

В образі FastAPI сам віддає зібраний фронт, тож CORS і `VITE_API_URL` не потрібні. Ваги CV вшиті в образ, а SQLite лежить у volume `vilno-data`.

## Структура

```
backend/app/{api,models,services,sim}/   FastAPI, тарифи, статуси скану, CV, симулятор

frontend/src/{pages,components,api,lib}/ екрани /driver /inspector /city
data/raw/                                оригінал набору з data.gov.ua
scripts/                                 import_lots.py, reset_db.py

```

## Статус

Це хакатонний прототип, зроблений за один день. Для реального продукту мобільний клієнт буде на React Native. Оплата є mock, а сесії та сканування — демонстраційні. Кількість авто, зайнятість і частка неоплати на дашборді — симуляція з фіксованим seed. Реальну частку неоплати міряє лише пілот зі сканами інспектора.
